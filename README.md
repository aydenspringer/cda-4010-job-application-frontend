# CDA 4010 UI Design Job Application Prototype

This is a simple web interface for the redesign of the paper job application onto a website.
This is frontend only using local storage, none of this is live, and none of this is affilicated
with UNF nor the job positions at UNF. This is a prototype assignment only.

This is a React application using Tailwind CSS and Shadcn/ui components.
Components in components/ui are by shadcn.

The App.tsx is a monolith file containing the FE's job application.

## Expanding the Oxlint configuration

If you are developing a production application, we recommend enabling type-aware lint rules by installing `oxlint-tsgolint` and editing `.oxlintrc.json`:

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "plugins": ["react", "typescript", "oxc"],
  "options": {
    "typeAware": true
  },
  "rules": {
    "react/rules-of-hooks": "error",
    "react/only-export-components": ["warn", { "allowConstantExport": true }]
  }
}
```

See the [Oxlint rules documentation](https://oxc.rs/docs/guide/usage/linter/rules) for the full list of rules and categories.
